Fine weave, in colour

The Fine weave dither, now with colour. Each tile uses a palette of a different size taken from the scene, from three inks up to sixteen, with the darkest always the ink and the lightest always the paper. Pixels start at Fine; Finest is one screen pixel per dot. Click any tile to see it full screen.
